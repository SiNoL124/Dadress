# دادرس (Dadress)

پلتفرم هوشمند تطبیق موکل و وکیل در ایران

پروژهٔ درس تحلیل و طراحی نرم‌افزار — ترم ۱۴۰۵

## دربارهٔ پروژه

دادرس یک سامانهٔ آنلاین است که به افراد کمک می‌کند برای مسائل حقوقی خود
وکیل مناسب پیدا کنند:

- ثبت مسئلهٔ حقوقی و دریافت پیشنهاد وکیل متناسب با تخصص
- مشاهدهٔ سابقه، نمره و نظرات دربارهٔ هر وکیل
- مقایسهٔ وکلا و ارسال درخواست پرونده
- پرسش حقوقی سریع (مشاورهٔ کوتاه) و دریافت پاسخ از وکیل مرتبط
