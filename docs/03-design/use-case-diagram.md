## ۵. شرح یک Use Case نمونه

### UC-10 — رزرو نوبت مشاوره

| مورد | توضیح |
|------|-------|
| Actor اصلی | موکل |
| پیش‌شرط | موکل وارد شده و وکیل دارای بازهٔ آزاد در تقویم است |
| جریان اصلی | ۱. موکل پروفایل وکیل را باز می‌کند ← ۲. بازهٔ آزاد و نوع مشاوره (حضوری یا تلفنی) را انتخاب می‌کند ← ۳. سیستم به صفحهٔ پرداخت می‌رود (UC-11) ← ۴. پس از پرداخت موفق، نوبت تأیید و بازه برای دیگران بسته می‌شود |
| جریان جایگزین | اگر بازه در همین لحظه رزرو شده باشد، پیام «این زمان دیگر آزاد نیست» نمایش داده می‌شود؛ اگر پرداخت ناموفق باشد، نوبت لغو و بازه آزاد می‌شود |
| پس‌شرط | نوبت با وضعیت «تأییدشده» ذخیره می‌شود |

### UC-09 — ثبت نمره و نظر

| مورد | توضیح |
|------|-------|
| Actor اصلی | موکل |
| پیش‌شرط | موکل وارد شده و از وکیل پاسخ، نوبت یا پروندهٔ پذیرفته‌شده دارد |
| جریان اصلی | ۱. موکل صفحهٔ وکیل را باز می‌کند ← ۲. «ثبت نظر» را می‌زند ← ۳. نمره (۱ تا ۵) و متن را وارد می‌کند ← ۴. ثبت می‌کند ← ۵. سیستم میانگین نمرهٔ وکیل را به‌روز می‌کند |
| جریان جایگزین | اگر موکل شرایط را نداشته باشد، پیام «فقط پس از دریافت خدمت می‌توانید نظر بدهید» نمایش داده می‌شود |
| پس‌شرط | نظر ذخیره و در پروفایل وکیل نمایش داده می‌شود |
